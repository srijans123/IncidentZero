# ADR-004: AI & Machine Learning Execution Model

## Status
Accepted

## Context
Intelligent features (A1 duplicate detection, A2 classification, A5 SLA breach risk, A6 case-based RAG) must operate reliably both online and in offline testing environments without flaky external dependencies.

## Considered Options
1. Python FastAPI microservice sidecar (runtime container sprawl and schema drift)
2. Cloud-only LLM API calls (quota exhaustion and network failure vulnerabilities)
3. In-process ONNX Runtime + Provider-Neutral `LanguageModelPort`

## Decision
Adopt **In-process ONNX Runtime + Provider-Neutral LanguageModelPort**.
- Calibrated tabular models execute in-process via ONNX Runtime (<5ms latency).
- LLM calls abstracted via `LanguageModelPort` with 9-stage decorator pipeline.
- First-class support for `AI_PROVIDER=replay` and `AI_PROVIDER=off` fallback.
