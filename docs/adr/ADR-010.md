# ADR-010: AI Security, Guardrails & LLM Decorator Chain

## Status
Accepted

## Context
AI integrations must guard against prompt injection, PII leakage, unbounded token consumption, and hallucinated source citations.

## Considered Options
1. Direct API calls from controllers/services (insecure and unmonitored)
2. Layered Decorator Chain on `LanguageModelPort`

## Decision
Adopt **Layered Decorator Pipeline on LanguageModelPort**.
- 9-stage pipeline: PiiRedaction, PromptGuard, SemanticCache, SchemaValidation, RateLimit, CircuitBreakerWithTimeout, Metering, ReplayRecorder.
- Closed-vocabulary schemas compiled to type-safe Java records.
- Deterministic citation verifier discards unsupported resolution steps.
- ArchUnit Rule R6 forbids `intelligence` from calling command services.
