# ADR-015: Frontend Architecture: React 19 Three-Workspace Role-Guarded PWA

## Status
Accepted

## Context
End-users, technicians, and administrators require purpose-built interfaces tailored to their workflows rather than a generic one-size-fits-all dashboard.

## Considered Options
1. Three separate single-page applications
2. Single unified React 19 application with role-guarded workspaces and real-time SSE streaming

## Decision
Adopt **React 19 + TypeScript + Vite + Tailwind CSS Three-Workspace PWA**.
- `/portal`: Voice-enabled copilot, self-help deflection, live ticket status and rating.
- `/workbench`: War room, dynamic action bar, AI panel with RAG citations and leaf-safe RCA.
- `/admin`: Interactive 19-node Service DAG canvas, cryptographic ledger verifier, and 40-ticket storm trigger.
- Instant user-switching between 8 seeded campus accounts for seamless live demos.
