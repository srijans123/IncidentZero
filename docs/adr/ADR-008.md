# ADR-008: Priority Calculation Engine (ITIL Matrix + Modifiers)

## Status
Accepted

## Context
Calculating priority via raw integer products ($Impact \times Urgency$) suffers from collisions ($2 \times 3 = 6 = 1 \times 6$). Priority must be explainable and auditable.

## Considered Options
1. Integer product multiplication formula (rejected due to priority collisions)
2. Opaque black-box ML scoring (rejected due to lack of explainability)
3. ITIL 3x3 Matrix + Bounded Additive Campus Modifiers

## Decision
Adopt **ITIL Matrix with Bounded Additive Campus Modifiers**.
- Base priority determined by ITIL matrix (P1 to P4).
- Additive modifiers (academic exam windows, VIP reporters, security category floor, affected user thresholds) capped at +1 level.
- Full mathematical derivation and reasoning captured in `PriorityExplanation`.
