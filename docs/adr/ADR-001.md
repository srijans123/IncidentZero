# ADR-001: Language & Runtime Selection (Java 25 LTS / Java 21 LTS)

## Status
Accepted

## Context
The ITSM core requires strict OOP modeling (sealed class hierarchies, exhaustive pattern matching, value objects) alongside high-throughput, low-latency concurrent SLA monitoring across thousands of active timers.

## Considered Options
1. Python 3.12 (weak runtime encapsulation, lack of strict interfaces)
2. TypeScript / Node.js (type erasure at runtime, single-threaded event loop)
3. Java 25 LTS / Java 21 LTS (Temurin OpenJDK)

## Decision
Adopt **Java 25 / Java 21 LTS**.
- Sealed types (`IncidentState`, `DomainEvent`) for exhaustive compile-time verification.
- Virtual Threads for lightweight asynchronous SLA scheduling.
- Records for immutable data transfer and value semantics.
- Zero dependencies in domain core (pure JDK).
