# ADR-007: Incident State Machine & Dual Pause-Aware SLA Clocks

## Status
Accepted

## Context
Incident lifecycle must strictly enforce 11 legal states and dual SLA clocks (response and resolution) that accurately pause during `PENDING_USER` and evaluate breaches before clock stoppage.

## Considered Options
1. Mutable enum with switch statements in service layers (leaks business logic)
2. Sealed State Pattern with polymorphic command dispatch

## Decision
Adopt **Sealed State Pattern (11 Concrete Classes) with polymorphic command dispatch**.
- `allowedCommands()` dynamically governs valid actions and UI button rendering.
- `SlaClock` preserves consumed working milliseconds across pauses and mode changes (`retarget()`).
- `stopResponse()` and `stopResolution()` evaluate breach status before stopping the clock so late acknowledgements never erase breaches.
