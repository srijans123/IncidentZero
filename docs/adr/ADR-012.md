# ADR-012: Quality Assurance, Verification & Fuzzing Harness

## Status
Accepted

## Context
The core state machine, audit ledger, and SLA clocks must be provably resilient across all possible legal and illegal command sequences.

## Considered Options
1. Unit tests covering standard happy paths only
2. 71-case test pyramid + standalone 50,000-sequence property verification harness

## Decision
Adopt **Comprehensive Test Pyramid + 50,000-Sequence Verify.java Harness**.
- `Verify.java` verifies 554,590 randomized state transitions with zero invariant violations.
- ArchUnit enforces architectural boundaries R1-R9.
- Milestone verification scripts `verify-m1.sh` through `verify-m6.sh` automate continuous gatekeeping.
