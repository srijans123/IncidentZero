# ADR-005: Real-Time Communication Protocol (Server-Sent Events with Stream Ticket)

## Status
Accepted

## Context
War room state changes, SLA countdown ticks, and storm simulation progress must stream to browsers in real time without polling. Browser `EventSource` cannot pass custom Authorization headers.

## Considered Options
1. Bidirectional WebSockets (heavier state management and complex handshake auth)
2. Short polling (high database load and latency)
3. Server-Sent Events (SSE) with Single-Use 30s Stream Ticket

## Decision
Adopt **Server-Sent Events (SSE) with Single-Use 30s Stream Ticket**.
- Client requests opaque ticket via `POST /api/v1/auth/stream-ticket`.
- Connects to `GET /api/v1/stream?ticket=<ticket>`.
- InAppSseHub maintains a 512-event circular ring buffer for `Last-Event-ID` reconnection replay and 15s heartbeats.
